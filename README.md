# cardiac-code

CARDIAC programs to read, run and learn from. They are part of Strange Query's
[CARDIAC collection](https://lab.strangequery.com/cardiac/).

- [`originalManual`](originalManual/) has every program in the original 1968 manual, transcribed exactly as printed.
- [`pearls`](pearls/) collects the tricks that make CARDIAC programs small and fast. They are also on the site as
  [Tips and tricks](https://lab.strangequery.com/cardiac/tips/).
- [`quine`](quine/) is a program that punches its own deck.
- [`sortem`](sortem/) sorts the numbers it reads, and its two-tape version shows how to run a program too big for
  memory.

Each program comes as a listing (`.cardiac`) and a deck (`.deck`). You can run them in
[Cardigan](https://lab.strangequery.com/cardigan/) or with `burn` from [heartburn](https://lab.strangequery.com/heartburn/).
